Vento Labs Notify API

Part of the /.well-known/api-catalog (RFC 9727).

Webhook used by ventolabs.com to forward visitor, booking, and session events to a Telegram channel. Also accepts Cal.com booking webhooks. Unauthenticated and CORS-open — the URL is exposed in the site's client bundle.

Endpoint

POST https://wlwmmyawxzspgwrijyvm.supabase.co/functions/v1/notify

Machine-readable spec

OpenAPI 3.1 — /.well-known/openapi/notify.json

Event types

  • type: "visit" — page view (sent once per session)
  • type: "booking" — booking-flow CTA clicked
  • type: "session" — session summary on tab hide / unload, sent via navigator.sendBeacon with Content-Type: text/plain
  • type: "lead" — lead-form submission (name, work email, free-text ask)
  • Cal.com webhook envelopes with triggerEvent ∈ { BOOKING_CREATED, BOOKING_RESCHEDULED }

Example

curl -X POST https://wlwmmyawxzspgwrijyvm.supabase.co/functions/v1/notify \
  -H "Content-Type: application/json" \
  -d '{"type":"visit","page":"/","referrer":"(direct)","ts":"2026-05-08T12:00:00Z"}'

Response: { "ok": true }

Status codes

  • 200 — accepted (and forwarded, or noted as unhandled)
  • 405 — method other than POST/OPTIONS
  • 500 — error forwarding to Telegram
