## 2. Что считаем целью

Трафик — не цель. Цель — заявки и записи на звонок из России.

Дерево метрик, сверху вниз:

1. **Заявки из органики РФ** (главная метрика)
2. Записи на звонок / переходы в Telegram
3. Визиты из поиска Яндекса и Google по России
4. Показы и средняя позиция по коммерческим русским запросам
5. Количество страниц в индексе Яндекса и Google

Пункты 4–5 — опережающие: они шевелятся первыми и показывают, работает ли
Спринт 0, задолго до того, как появятся заявки.

## 3. Цели в Яндекс.Метрике

Завести сразу при создании счётчика, до того как пойдёт трафик — иначе первые
недели данных пропадут.

| Цель | Тип | Условие |
|---|---|---|
| Клик по телефону | phone | автоцель Метрики |
| Переход в Telegram | messenger | автоцель Метрики |
| Отправка формы | form | автоцель или JS-событие из `notifyLead` |
| Запись на звонок | JS-событие | `ym(ID,'reachGoal','booking')` в `notifyBooking()` |
| Открытие страницы услуги | url | `/ru/services/` |

В `src/lib/notify.ts` уже есть три точки — `notifyVisit`, `notifyLead`,
`notifyBooking`. Достаточно дописать в каждую вызов `reachGoal`, и цели
поедут без отдельной разметки.

То же самое стоит продублировать в GTM для Google Analytics, если он
используется.

## 4. Регулярные отчёты

### Еженедельно (10 минут)

Из Search Console и Вебмастера:
- клики и показы с фильтром «страна = Россия»;
- сколько URL в индексе (Вебмастер -> Индексирование -> Страницы в поиске);
- новые запросы, по которым появились показы.

Из Метрики:
- визиты из поиска, достижения целей, источники.

Фильтр по России обязателен всегда. Без него испаноязычный шум (A-04) забивает
любую динамику.

### Ежемесячно

- Прогон краула OpenSEO по тому же проекту — сравнение с предыдущим.
- Проверка позиций по коммерческим русским запросам. Важно: снимать в
  Яндексе, Google-инструменты по РФ не работают (A-14).
- Проверка ссылочного: появились ли новые домены.

### Ежеквартально

- Полная перепроверка индексации: сколько из 80 URL Google и Яндекс реально
  знают.
- Пересмотр контент-плана по реальным запросам из Вебмастера, а не по
  гипотезам.

## 5. Замер цитируемости в ИИ-ассистентах (GEO)

Отдельная процедура, потому что автоматических метрик тут нет.

Раз в месяц задавать один и тот же набор вопросов в ChatGPT, Claude, Алисе,
GigaChat и Perplexity, в новой сессии, без упоминания бренда:

```
Кто в России делает системы учёта с AI-агентом под заказ?
Кто внедряет AI-агентов к 1С?
Кому заказать SEO-аудит и подготовку сайта под нейросети?
Кто делает автоматизацию для продавцов на Wildberries и Ozon?
```

Записывать: упомянули ли Vento Labs, с какой формулировкой, дали ли ссылку.
Хранить ответы в `evidence/geo-YYYYMM/`. Это единственный честный способ
увидеть динамику — «ощущение, что стали чаще упоминать» метрикой не является.

Спринте 0, и надо возвращаться туда, а не писать новые статьи.

## 7. Честные риски

- **Индексация может занять дольше.** У домена мало ссылок (19 доменов,
  rank 10), краул-бюджет маленький. Месяц — оптимистичная оценка, два —
  реалистичная.
- **Испаноязычный трафик продолжит падать.** Июль 1 318 -> сентябрь 174.
  Суммарные цифры по сайту будут ухудшаться, даже если российское направление
  растёт. Поэтому отчёт ведём только по срезу «Россия».
- **Хостинг на GitHub Pages через Frankfurt.** Скорость и доступность из России
  из этой сессии не измерялись — утверждать, что это проблема, нельзя. Но
  проверить из российской сети стоит, и если отклик плохой, вариант с
  российским хостингом или CDN надо рассматривать.
- **Яндекс медленнее Google на молодых доменах.** Первые месяцы данных будет
  мало; это нормально, а не признак ошибки.
