# Аудит ventolabs.com: находки

Дата: 21 сентября 2026. Источники и границы — в `README.md`. Сырые выгрузки — в `evidence/`.

Приоритет проставлен по одному критерию: насколько находка мешает получить
российского клиента из поиска.

---

## A-01 [Критично] Sitemap не отправлен в Search Console — 68 из 80 страниц Google не знает

**Что видно.** Запрос списка сайтмапов у Google Search Console для
`sc-domain:ventolabs.com` возвращает пустой массив. Ни одного сайтмапа не
отправлено за всё время.

**К чему это привело.** Точечная проверка статуса индексации (URL Inspection
API, 10 адресов):

| URL | Вердикт Google |
|---|---|
| `/ru/` | Submitted and indexed, последний обход 17.09.2026 |
| `/ru/services/ai-automation/` | **URL is unknown to Google** |
| `/ru/services/ai-workspace/` | **URL is unknown to Google** |
| `/ru/cases/erp-agent/` | **URL is unknown to Google** |
| `/ru/blog/ai-agent-dlya-1c-vnedrenie/` | **URL is unknown to Google** |
| `/services/ai-automation/` | **URL is unknown to Google** |
| `/blog/` | **URL is unknown to Google** |
| `/blog/custom-ai-agent-cost/` | **URL is unknown to Google** |
| `/cases/erp-agent/` | **URL is unknown to Google** |
| `/es/services/ai-automation/` | **URL is unknown to Google** |

«Unknown to Google» — это не «просканировано и отброшено». Это значит, что
робот на этих адресах не был ни разу.

**Подтверждение с другой стороны.** За 90 дней хотя бы один показ в выдаче
получили ровно 12 URL из 80. Все четыре главные, четыре юридические страницы,
`/data-centers/` и один немецкий кейс. Ни одной страницы услуги. Ни одной
статьи блога.

**Почему это не проблема разметки.** HTML отдаётся сервером готовым, ссылки на
внутренние страницы есть в исходном коде (13–16 входящих внутренних ссылок на
страницу по данным краула), robots.txt разрешает всё, canonical корректные.
Краулинг не заблокирован — на сайт просто не приходят.

**Причина.** Нет сайтмапа в GSC + почти нет внешних ссылок (см. A-07), поэтому
у Google нет ни карты, ни причины тратить краул-бюджет на внутренние страницы
маленького домена.

**Что делать.** Отправить `https://ventolabs.com/sitemap.xml` в Search Console
и в Яндекс.Вебмастер, включить IndexNow (A-11), вручную запросить индексацию
приоритетных 10–15 URL.

> Попытка отправить сайтмап из этой сессии программно вернула
> `Request had insufficient authentication scopes` — у подключённого OAuth-токена
> только права на чтение. Отправлять придётся из интерфейса GSC либо перевыдать
> токен с правом записи.

## A-02 [Критично] Домен не заведён в Яндекс.Вебмастере

**Что видно.** Подключённый аккаунт Яндекс.Вебмастера (user_id 1130000051770399)
содержит ровно один сайт — `https://prompoint.ru/`. `ventolabs.com` в списке
отсутствует.

**Что это значит.** Мы не знаем про Яндекс вообще ничего: ни сколько страниц в
индексе, ни какие запросы показывают сайт, ни есть ли санкции или проблемы
обхода. Это не «ноль трафика из Яндекса» — это отсутствие измерения.

При этом Яндекс — основной поиск на российском десктопе и в Поиске с Алисой.
Для цели «клиенты из России» неподключённый Вебмастер — это отключённый канал.

**Что делать.** Добавить хост, подтвердить права (проще всего — файлом в
`public/`, он попадает в `out/` при экспорте), отправить сайтмап, включить
обход по счётчику Метрики, выставить региональность.

## A-03 [Критично] Яндекс.Метрики нет

**Что видно.** В HTML живого сайта нет ни одного обращения к `mc.yandex.ru`.
В подключённом аккаунте Метрики счётчика для ventolabs.com не существует
(доступен только счётчик 18395611 чужого проекта).

**Что это значит.**
- Нет Вебвизора, карты кликов и карты скроллинга — для продающей страницы это
  основной инструмент правок.
- Нет целей: «клик по телефону», «переход в Telegram», «отправка формы»,
  «запись на звонок». Сейчас ни одно из этих действий нигде не считается.
- Яндекс не может использовать поведенческие данные счётчика при обходе и
  ранжировании.
- GTM и PostHog стоят, но по российской аудитории они дают меньше, а PostHog
  в российском контуре ещё и нестабилен.

**Что делать.** Завести счётчик, поставить код, объявить 5 целей, связать с
Вебмастером. Готовый компонент и набор целей — в `implementation-plan.md`.

владельца этот трафик надо считать за ноль и отсекать в отчётах фильтром по
стране/языку.

## A-07 [Высокий] Оффер не адаптирован под российского покупателя

**Что видно на `/ru/`:**

- Цена указана только в долларах: «$500» встречается на русской главной
  23 раза. Символа ₽ на странице нет ни разу.
- Контакты: WhatsApp на мексиканский номер (`wa.me/529998023600`) и личный
  Telegram (`t.me/defi_defiler`). Российские номера в проекте есть
  (`+7 903 233 35 25`, `+7 994 318 21 88` в `src/lib/site.ts`), но на русской
  главной не используются.
- Запись на звонок — через cal.com, без русскоязычного объяснения и без
  альтернативы «написать в Telegram прямо сейчас».
- Нет ни слова о том, как российская компания это оплачивает и по какому
  договору. Для B2B-заказа на несколько сотен тысяч рублей это первый вопрос,
  а не десятый.

**Вывод.** Даже если завтра включить индексацию и привести людей, страница
теряет их на трёх подряд стопах: непонятная валюта, зарубежный контакт,
непонятная схема оплаты.

## A-08 [Высокий] Нет посадочных под то, что реально заказывают

**Что есть сейчас** — четыре услуги, все абстрактные:
`ai-assistant`, `ai-automation`, `ai-training`, `ai-workspace`.

**Чего нет** (из описания спроса, который владелец видит на практике):

1. **Система учёта под бизнес**: дашборд, куда заходишь, добавляешь,
   смотришь; опционально витрина/сайт, куда товары попадают из этого дашборда;
   агент, который считает математику и сверяет данные.
2. **SEO/GEO-аудит и подготовка сайта под нейросети** — работа, которая уже
   сделана для krasivobrat.ru и arbitrai.tech, но на сайте не оформлена как
   услуга и не имеет посадочной.

Это два самых конкретных и самых дорогих запроса, и под них на сайте нет ни
одной страницы, которая могла бы ранжироваться.

**Вывод.** Даже при идеальной индексации ранжироваться будет нечему: под
коммерческий спрос нет документов. Состав страниц — в `content-plan.md`.

- обратных ссылок: 36

Яндекс к этому ещё чувствительнее, чем Google.

## A-10 [Средний] Технические мелочи из краул-аудита

Краул 60 страниц + Lighthouse на 20. Критичных ошибок нет ни одной. Всё
найденное — уровня «info», 118 штук:

| Проблема | Страниц |
|---|---|
| Пропуск уровня заголовков (h2 -> h4 и т.п.) | 60 |

| Description короче рекомендуемого | 3 |

Отдельно хорошее, что стоит зафиксировать: среднее время ответа по 60
страницам — **74 мс**, все ответы 200, все страницы индексируемы, все в
sitemap. База здоровая.

Заголовок `last-modified` главной — `Mon, 10 Aug 2026 05:42:15 GMT`. Сорок
дней без единого обновления. Для домена, которому и так не хватает

## A-12 [Низкий] Нет IndexNow

IndexNow — протокол мгновенного уведомления о новых и изменённых URL, который
поддерживают Яндекс и Bing. Для статического сайта на GitHub Actions это
пятнадцать строк в workflow и один файл-ключ в `public/`. Сейчас не подключено.

Для Яндекса это самый дешёвый способ сократить срок попадания страницы в индекс
с недель до дней.

---

## A-13 [Низкий] GEO-обвязка сделана, но только по-английски

Сайт неплохо подготовлен к ИИ-ассистентам: есть `llms.txt` (14 КБ),
`.well-known/agent-card.json`, `.well-known/mcp`, `.well-known/openapi`, в
robots.txt объявлен `Content-Signal: search=yes, ai-input=yes, ai-train=no`.
Это заметно лучше, чем у 99% сайтов.

Но `llms.txt` написан целиком по-английски. Русская версия — 7 ссылок на
`/ru/` внутри английского текста. Для русскоязычных ассистентов (Алиса,
GigaChat, русские сессии ChatGPT/Claude) не хватает русского описания сущности,
услуг и цен.

## A-14 [Инфо] Google-инструменты не покрывают Россию

При попытке создать проект с локацией «Россия» DataForSEO возвращает
`Unsupported DataForSEO location code`. Поиск локаций по коду страны RU не
находит ни одного города. Ближайший доступный русскоязычный рынок —
Казахстан (код 2398), но объёмы там на порядок меньше российских: проверочный
прогон по сидам «ai агент для бизнеса», «внедрение искусственного интеллекта в
бизнес», «разработка crm системы на заказ» дал частотности 10–40 в месяц, что
для планирования по РФ бесполезно.

**Практический вывод.** Частотность и конкуренцию по России берём из Wordstat
и Яндекс.Директа, а не из Google-инструментов. Любой отчёт, где «спрос в РФ»
посчитан по DataForSEO, — недостоверен.
