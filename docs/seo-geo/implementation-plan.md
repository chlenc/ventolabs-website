### 0.4 [владелец + код] Поставить Яндекс.Метрику

1. Создать счётчик на ventolabs.com. Включить Вебвизор, карту скроллинга и
   отслеживание хеша.
2. Записать ID счётчика в `.env.production` как
   `NEXT_PUBLIC_YANDEX_METRIKA_ID`.
3. Добавить компонент (код ниже) в `src/app/layout.tsx` и
   `src/app/[lang]/layout.tsx` рядом с `GoogleTagManager`.
4. Связать счётчик с Вебмастером (Вебмастер -> Настройки -> Метрика).

Компонент писать так, чтобы без переменной он ничего не рендерил — тогда
локальная разработка и превью не засоряют статистику:

```tsx
// src/components/YandexMetrika.tsx
"use client";
import Script from "next/script";

const ID = process.env.NEXT_PUBLIC_YANDEX_METRIKA_ID;

export function YandexMetrika() {
  if (!ID) return null;
  return (
    <>
      <Script id="ym" strategy="afterInteractive">{`
        (function(m,e,t,r,i,k,a){m[i]=m[i]||function(){(m[i].a=m[i].a||[]).push(arguments)};
        m[i].l=1*new Date();k=e.createElement(t),a=e.getElementsByTagName(t)[0],
        k.async=1,k.src=r,a.parentNode.insertBefore(k,a)})
        (window,document,"script","https://mc.yandex.ru/metrika/tag.js","ym");
        ym(${ID},"init",{webvisor:true,clickmap:true,trackLinks:true,
        accurateTrackBounce:true,trackHash:true});
      `}</Script>
      <noscript>
        <div><img src={`https://mc.yandex.ru/watch/${ID}`} style={{position:"absolute",left:"-9999px"}} alt="" /></div>
      </noscript>
    </>
  );
}
```

Закрывает: A-03.

1. Сгенерировать ключ (32 hex-символа), положить
   `public/<key>.txt` с этим же ключом внутри.
2. В `.github/workflows/deploy.yml` после успешного деплоя отправлять список

workflow. Закрывает: A-12.

Выдуманная дата хуже отсутствующей — её ставить нельзя.

`src/lib/i18n/dictionaries/*.ts`, блоки `seo`. Цель — title до ~60 символов,
description 120–160. Русские длиннее английских, поэтому начинать с `ru.ts`.

### 1.4 [код] Порядок заголовков
